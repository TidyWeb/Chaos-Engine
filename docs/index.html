Practise on data that fights back

Public datasets are usually already cleaned, which is not how real work looks.
  1. Load any dataset you like (a Kaggle download, say).
  2. Check the column types it guessed.
  3. Press Create Chaos, then download the messy file and clean it up.
Download the answer key afterwards to see exactly what was changed, row by row.
